# 스킬 아이콘

이 폴더에 스킬 로고 이미지를 넣으면 `SkillCard`가 자동으로 표시합니다.

- 파일명은 `src/data/skills.ts`의 각 항목 `id`와 동일하게 (확장자는 svg / png / webp / jpg 아무거나)
- 파일이 없으면 기존 회색 원형 플레이스홀더가 그대로 보입니다.

필요한 파일:

| id | 파일 예시 |
|----|----------|
| `react` | `react.svg` |
| `typescript` | `typescript.svg` |
| `java` | `java.svg` |
| `springboot` | `springboot.svg` |
| `mysql` | `mysql.svg` |
| `git` | `git.svg` |
| `docker` | `docker.svg` |
